feat(icons): 图标选择器改用官方 DSH 图标集 + 弹出式分页网格

阶段 D（用户反馈 1/2）：

- 需求「能否使用 dsh 系统中的图标系统」：DSH 确实有图标系统
  （@deepseek-ai/dsh-client-ui-primitives，70 个 Icon*Outline），且它是客户端
  静态种子模块、require 就能拿到。但那些是 React 组件，而本插件客户端是纯
  DOM（React 只作 settings 薄封装）—— 为 14px 字形往每个侧边栏行塞 React
  元素树不划算。改为**内联上游的 path 数据**：图形与 DSH 逐字一致，零运行时
  依赖、不扩大 bundle 的 peer 面。
- 新增 scripts/gen-wiki-icons.mjs + scripts/extract-dsh-icons.mjs：从本机 DSH
  checkout 提取官方 path，生成 src/client/wiki-icon.generated.ts（36 个官方
  图标 + 6 个自绘）。生成脚本入库，数据可复现、不会与上游漂移。
- 图标从 8 个扩到 42 个；选择器从 <select> 改为**弹出式网格 + 分页**
  （48/页，上一页/下一页，单页时不显示分页），每个格子渲染真实图标 ——
  原生下拉只能显示文字，扫不过来也画不出来。用户的自定义 emoji 仍被保留。

守门：verify-wiki-focus 断言 host 名单与客户端可渲染集合**双向**一致
（不一致会表现为「选了不生效」或静默回落默认图标），并断言分页控件存在。
